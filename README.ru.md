## Что такое Paperclip?

# Оркестрация с открытым кодом для компаний без людей

**Если OpenClaw — это _сотрудник_, то Paperclip — _компания_**

Paperclip — это сервер на Node.js и интерфейс на React, который оркестрирует команду AI-агентов для управления бизнесом. Подключите своих агентов, поставьте цели и отслеживайте их работу и расходы из одного дашборда.

Выглядит как таск-менеджер, но внутри — оргструктуры, бюджеты, управление, согласование целей и координация агентов.

**Управляйте бизнес-целями, а не pull request'ами.**

|        | Шаг                | Пример                                                                        |
| ------ | ------------------ | ----------------------------------------------------------------------------- |
| **01** | Определите цель    | _«Построить AI-приложение для заметок №1 до $1M MRR.»_                        |
| **02** | Наймите команду    | CEO, CTO, инженеры, дизайнеры, маркетологи — любой бот, любой провайдер.      |
| **03** | Одобрите и запустите | Проверьте стратегию. Задайте бюджеты. Нажмите «go». Следите из дашборда.   |

<br/>

> **СКОРО: Clipmart** — Скачивайте и запускайте целые компании в один клик. Выбирайте готовые шаблоны — полные оргструктуры, конфиги агентов и скиллы — и импортируйте в свой Paperclip за секунды.

## Paperclip вам подойдёт, если

- ✅ Хотите строить **автономные AI-компании**
- ✅ **Координируете разных агентов** (OpenClaw, Codex, Claude, Cursor) к общей цели
- ✅ У вас **открыто 20 терминалов Claude Code** и вы теряете нить, кто чем занят
- ✅ Хотите, чтобы агенты работали **автономно 24/7**, но оставалась возможность проверять и вмешиваться
- ✅ Хотите **контролировать расходы** и ставить бюджеты
- ✅ Хотите управлять агентами так, чтобы **это ощущалось как таск-менеджер**
- ✅ Хотите управлять автономным бизнесом **с телефона**

## В чём особенность Paperclip

Paperclip правильно решает сложные детали оркестрации.

|                                   |                                                                                                                |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Атомарное выполнение.**         | Захват задачи и контроль бюджета атомарны — нет двойной работы и убегающих расходов.                           |
| **Живое состояние агента.**       | Агенты продолжают ту же задачу между хартбитами, а не начинают с нуля.                                         |
| **Внедрение скиллов в рантайме.** | Агенты учат воркфлоу Paperclip и контекст проекта прямо на ходу, без дообучения.                               |
| **Управление с откатом.**         | Шлюзы согласования работают, изменения конфигов версионируются, плохие правки откатываются безопасно.          |
| **Целенаправленное выполнение.**  | Задачи несут полную иерархию целей — агент видит не только заголовок, но и «зачем».                            |
| **Переносимые шаблоны компаний.** | Экспорт/импорт оргструктур, агентов и скиллов с очисткой секретов и обработкой коллизий.                       |
| **Настоящая изоляция компаний.**  | Каждая сущность привязана к компании — один деплой держит много компаний с отдельными данными и аудит-логами.  |

## Чем Paperclip НЕ является

|                                 |                                                                                                                  |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Не чатбот.**                  | У агентов работа, а не чат-окна.                                                                                 |
| **Не фреймворк для агентов.**   | Мы не говорим, как строить агентов. Мы говорим, как управлять компанией, состоящей из них.                        |
| **Не построитель воркфлоу.**    | Никакого drag-and-drop. Paperclip моделирует компании — с оргструктурами, целями, бюджетами и управлением.        |
| **Не менеджер промптов.**       | Агенты приходят со своими промптами, моделями и рантаймами. Paperclip управляет организацией, где они работают.  |
| **Не инструмент для одного агента.** | Это для команд. Один агент — Paperclip, скорее всего, не нужен. Двадцать — точно нужен.                      |
| **Не инструмент ревью кода.**   | Paperclip оркестрирует работу, а не pull request'ы. Процесс ревью — свой.                                         |

## Быстрый старт

Open source. Self-hosted. Учётка Paperclip не нужна.

```bash
npx paperclipai onboard --yes
```

Эта команда теперь по умолчанию запускает доверенный локальный loopback-режим для самого быстрого первого запуска. Чтобы стартовать в аутентифицированном/приватном режиме — выберите bind-пресет явно:

```bash
npx paperclipai onboard --yes --bind lan
# или:
npx paperclipai onboard --yes --bind tailnet
```

Если Paperclip уже настроен, повторный `onboard` оставит текущий конфиг нетронутым. Для правки настроек используйте `paperclipai configure`.

Или вручную:

```bash
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm dev
```

Команда поднимет API-сервер на `http://localhost:3100`. Встроенная PostgreSQL создаётся автоматически — настройка не нужна.

> **Требования:** Node.js 20+, pnpm 9.15+

## FAQ

**Как выглядит типичная установка?**
Локально — один процесс Node.js со встроенным Postgres и локальным файловым хранилищем. Для продакшена — свой Postgres и деплой куда угодно. Настраиваете проекты, агентов и цели — остальное делают агенты.

Соло-предприниматель? Можно подключаться к Paperclip через Tailscale из любой точки. Потом при необходимости задеплоить, например, на Vercel.

**Можно вести несколько компаний?**
Да. Один деплой держит неограниченное число компаний с полной изоляцией данных.

**Чем Paperclip отличается от агентов типа OpenClaw или Claude Code?**
Paperclip _использует_ этих агентов. Собирает их в компанию — с оргструктурой, бюджетами, целями, управлением и подотчётностью.

**Почему Paperclip, а не OpenClaw, подключённый к Asana или Trello?**
У оркестрации агентов много тонкостей: отслеживание захвата задач, поддержание сессий, мониторинг расходов, настройка управления. Paperclip делает это за вас.

(Bring-your-own-ticket-system — в roadmap.)

**Агенты работают непрерывно?**
По умолчанию агенты запускаются по хартбитам и событийным триггерам (назначение задачи, упоминания через @). Можно также подключить непрерывных агентов типа OpenClaw. Вы приносите агента, Paperclip координирует.

## Разработка

```bash
pnpm dev              # Полный dev (API + UI, watch-режим)
pnpm dev:once         # Полный dev без слежения за файлами
pnpm dev:server       # Только сервер
pnpm build            # Сборка всего
pnpm typecheck        # Проверка типов
pnpm test             # Быстрый прогон тестов по умолчанию (только Vitest)
pnpm test:watch       # Vitest watch-режим
pnpm test:e2e         # Playwright браузерный набор
pnpm db:generate      # Сгенерировать миграцию БД
pnpm db:migrate       # Применить миграции
```

`pnpm test` не запускает Playwright. Браузерные наборы отдельно — их обычно запускают только при работе с этими сценариями или в CI.

Полный гайд по разработке — [doc/DEVELOPING.md](doc/DEVELOPING.md).

## Телеметрия

Paperclip собирает анонимную телеметрию использования, чтобы понимать, как продукт используется, и улучшать его. Никакая персональная информация, содержимое задач, промпты, пути к файлам или секреты не собираются. Ссылки на приватные репозитории хешируются с солью, уникальной для каждой инсталляции, перед отправкой.

Телеметрия **включена по умолчанию** и отключается любым из способов:

| Способ               | Как                                                        |
| -------------------- | ---------------------------------------------------------- |
| Переменная окружения | `PAPERCLIP_TELEMETRY_DISABLED=1`                           |
| Стандартное соглашение | `DO_NOT_TRACK=1`                                         |
| CI-окружения         | Автоматически отключается при `CI=true`                    |
| Файл конфига         | Установите `telemetry.enabled: false` в конфиге Paperclip  |
